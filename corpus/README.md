# Guideline corpus

Short, plain-language **educational summaries** of widely used acute-care
early-warning and escalation guidance, written for this capstone. Each file has
front matter (`title`, `source`, `topic`) and Markdown body text; the `source`
line names the real-world guideline the summary is based on.

These documents are **not clinical guidance** and must not be used for patient
care. They exist only as retrieval material for the RAG stage of the pipeline.

| File | Topic |
|------|-------|
| `news2-escalation.md` | NEWS2 parameters and escalation thresholds |
| `sepsis-screening.md` | when to screen for sepsis, the Sepsis Six |
| `acute-hypoxaemia-oxygen.md` | oxygen targets and the falling-SpO2 response |
| `hypotension-shock.md` | blood-pressure thresholds, approach to hypotension |
| `tachycardia-af-rvr.md` | new tachycardia and fast atrial fibrillation |
| `temperature-derangement.md` | fever and hypothermia |
| `altered-consciousness.md` | new confusion and reduced consciousness (ACVPU) |
